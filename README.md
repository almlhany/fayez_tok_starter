# FayezTok — القاعدة الأولى

هذه نسخة بداية تعمل كواجهة ويب متجاوبة، وتستخدم Firebase للمستخدمين وقاعدة البيانات وتخزين الفيديو. ليست نسخة كاملة من TikTok بعد.

## 1) أنشئ مشروع Firebase
1. افتح https://console.firebase.google.com/ وسجّل الدخول بحساب Google.
2. اضغط Add project وأنشئ مشروعًا.
3. من Project settings > General > Your apps، أضف تطبيق Web (الرمز `</>`).
4. انسخ إعدادات `firebaseConfig` التي يعطيك إياها Firebase إلى أعلى `app.js` بدل القيم التجريبية.

## 2) فعّل الخدمات
1. Authentication > Get started > Sign-in method > فعّل Email/Password.
2. Firestore Database > Create database.
3. Storage > Get started. قد يطلب إعداد فوترة حسب سياسة Firebase الحالية.
4. في Firestore Rules الصق محتوى `firestore.rules` ثم Publish.
5. في Storage Rules الصق محتوى `storage.rules` ثم Publish.

**تنبيه أمان:** هذه قواعد MVP تعليمية وليست قواعد إنتاج نهائية. عدّاد الإعجابات قابل للتلاعب لأنه يحدث من العميل؛ قبل الإطلاق العام انقله إلى Cloud Functions/خادم موثوق، وأضف مراجعة المحتوى ومكافحة الإساءة وحدود الرفع وسياسة خصوصية وشروط استخدام. الفيديوهات هنا عامة القراءة، فلا ترفع محتوى خاصًا.

## 3) افتح المشروع في Acode
1. فك ضغط ملف ZIP داخل مجلد يسهل الوصول إليه.
2. افتح Acode > Open Folder واختر مجلد `fayez_tok`.
3. عدّل `app.js` وأدخل إعدادات Firebase.
4. شغّل `index.html` عبر معاينة Acode إذا كانت تدعم ES modules وHTTPS. إذا فشلت المصادقة أو استيرادات Firebase، انشر المجلد على استضافة HTTPS مثل Firebase Hosting أو GitHub Pages. Firebase Auth المسموح به قد يتطلب إضافة نطاق الاستضافة في Authentication > Settings > Authorized domains.

## ما الموجود؟
- تسجيل حساب بالبريد وكلمة المرور وتسجيل الدخول والخروج.
- رفع فيديو حتى 100MB (حد مبدئي داخل الواجهة).
- موجز فيديوهات مباشر مرتب بالأحدث.
- إعجاب ومشاركة رابط.

## ما الذي لم يُبنَ بعد؟
التعليقات، المتابعة، الرسائل الخاصة، الإشعارات، البحث، التوصيات، الفلاتر والتحرير المتقدم، البث المباشر، الإبلاغ والإشراف. هذه مراحل لاحقة.

## النشر عبر الإنترنت
للتجربة الأولية استخدم استضافة HTTPS. لا تشارك كلمة مرور حساب Google أو أي مفاتيح سرية. إعدادات Firebase للويب ليست كلمة مرور إدارية، لكن قواعد الخدمات هي التي تحمي البيانات.
